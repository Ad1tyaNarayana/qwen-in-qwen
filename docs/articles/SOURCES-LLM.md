# Evidence ledger for the tiny LLM article

This ledger covers `tiny-llm-inside-qwen.md` and `figures-llm/`. Paths are relative to the repository root. Numeric identifiers such as Qwen3.5, RV32IM, NDOT4, int8, BF16, and SHA-256 name architectures, operations, formats, or algorithms. They are not additional benchmark results. Dates identify records. Drawing coordinates, colors, and font sizes are layout choices.

“Measured” includes execution counts, artifact sizes, exact comparisons, and constructor inventory. “Derived” means arithmetic on those records. “Projected” applies a bounded rate to a different workload. A complete run uses the compact fused executor unless stated otherwise. Ordinary stock `Qwen3_5ForCausalLM.generate` results are bounded prefixes, and the tiny Qwen3.5 stock prefix completes no guest prediction.

## Reproduction and limits

From the repository root, run `.venv/bin/python docs/articles/figures-llm/make_figures.py` to regenerate figures. The controlled chart is skipped while its evidence is absent. The measured table and correction notes are refreshed by `experiments/checkpoint-integrity/publish.py` only after validation passes.

Large raw traces, ELF/model images, and tensor checkpoints remain private under `.cache/checkpoint-integrity/` and the new GPU artifact directory. The public scripts retain commands, input hashes, checks, and source bindings. Public JSON can be checked for arithmetic and consistency, but does not by itself reproduce or attest GPU execution.

The earlier Doom article contains no 3.4×, 5.3×, or 1.86× claim. Its historical full-frame ratio remains qualified as a cross-network comparison where applicable. The dated LLM correction links the new controlled comparison without redefining those Doom measurements.
