# Qwenputer

The runtime imports Qwenputer from https://github.com/divagr18/qwenputer at revision ca13310e2f9f788d1dd3feeea8213c1b0c23913c. Compiled model construction in tools/hf_smoke.py and the CUDA and RAM experiments adapts upstream chipformer/rv/tiny.py. The firmware build uses upstream's linker script. The original Weight Paddle CHIP-8 ROM is generated by this repository and does not use upstream game ROMs.
